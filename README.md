# TROUV'OBJET — prototype de test

Prototype front-end statique en français pour explorer le parcours acheteur / vendeur.

## Tester en local
1. Télécharger les trois fichiers `index.html`, `styles.css` et `app.js`.
2. Ouvrir `index.html` dans un navigateur récent.
3. Tester les onglets Acheteur, Vendeur et Offres.

## Ce que cette version permet
- Publier une recherche de démonstration (objet, budget, état, ville et réception).
- Importer plusieurs photos, puis confirmer ou ignorer chaque objet.
- Conserver les données dans le stockage local du navigateur.
- Voir les correspondances simulées et proposer un prix.
- Parcourir les propositions avec les boutons ou un glissement horizontal : droite pour marquer son intérêt, gauche pour passer.

## Limites importantes
- C'est une démonstration locale : les données ne sont pas partagées entre appareils ou utilisateurs.
- Aucun vendeur réel n'est notifié et aucun achat/paiement n'est effectué.
- La reconnaissance d'objets par IA, les comptes utilisateurs, le serveur, la messagerie et les notifications réelles ne sont pas encore intégrés.
- Les correspondances sont des règles simples sur le texte, le prix et l'état ; ce n'est pas encore un moteur de recommandation intelligent.
- Les images et données restent dans le navigateur utilisé pour le test. Évite d'y importer des photos ou informations sensibles.
